# 停止确认修复与离线验证

日期：2026-10-09。本次只修改本地 MCU 和 PC 模拟器、同步协议说明。不连接串口、调试器或相机，不烧录，不操作机械臂或激光。不能据软件通过宣布实物停止验收完成。

## 1. 修复内容

- `APP/robot.c/.h`：中止接口返回五轴 CAN 停止应答检查结果，始终保留中止锁存；增加运动执行任务的活动标记，覆盖旧事件丢弃、拒绝及正常退出；只在任务退出、队列为空、中止锁存仍在且读取期间代次未变化时提供完整的新五轴反馈。
- `APP/robot_workflow.c/.h`：中止接受与停止确认分开。CAN失败不发送成功保持；确认读取三次完整反馈，间隔至少100毫秒、覆盖至少200毫秒，相对首样本变化不超过0.10度，预算2秒。缺帧或仍在执行打断稳定证据。超时 / 失败回匹配SEQ的FAULT_HOLD / MOTION_FAILED，并保持关输出与重启锁。
- 中止重复请求不延长预算；等待中的不同SEQ并入同一确认并各自应答；缓存保护未完成中止，满时拒绝新增请求，不丢旧确认。普通故障或停止未确认后不能直接START_MEASURE，须先解除故障并通过新的显式ABORT确认，再开始新轮。不会自动HOME或续跑。
- PC扫描页：ACK、扫描TERMINATED及故障不解除控制锁。仅匹配ABORT请求的WORKFLOW停止成功应答解锁；失败 / 3秒超时停心跳并显示停止未确认，拒绝晚到成功恢复。重复点击等待中的中止不续期。
- 报文字节保持原定义，未修改FK、DH、方向、轨迹配方、视觉增益、安全距离或目标 / 医生许可接口。给Jetson的完整约定在`doc/MCU冻结通信字节表与待确认项.md`第5.1节。
