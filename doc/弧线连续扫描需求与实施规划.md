## 1. 业务范围

```text
原开始 -> HOME -> 公共测距位 -> 新深度稳定锁存
  -> 正式左视准备并校验
  -> 左 → 正（途经、不停车）→ 右连续扫描
  -> 右端真实停稳并校验，SCAN_DONE
  -> MCU自动HOME并校验，HOME_READY
  -> MCU自动正式正视，最终五轴校验，FRONT_OBSERVE_READY
  -> 保持、输出关闭
  -> Jetson数字人选具体痣 -> 当前画面复核同一颗
  -> 显式原02启动 -> 原视觉对准/P000等联锁
```

整个右端 → HOME → 最终正视由MCU在原扫描请求内完成，不等Jetson发HOME/GOTO/SELECT。左/正/右是运动配方，不是痣编号。预置人脸模型用于展示，不要求真实三维重建、逐帧FK、手眼标定或痣基座XYZ。

本批不新增医生许可/身份协议、连续深度保护、HOME出画保护或完整FK修正；也不修改原视觉方向、输出上限或安全距离。原定靶02/03/81交接已接通，但不能称为具有未实现的目标身份/医生许可字段。

## 4. 原测距与停止职责

Jetson在原窗口上传有效原始相机深度D，05/LEN3，不扣5毫米突出量。MCU仍要求D≥100毫米、3个不同非零SEQ有效样本锁存；valid0或过近清初始计数。原逐步撤离及到位后重新测距不变。

锁存后的扫描/HOME/自动正视不新增持续距离阈值、缺帧看门狗或HOME出画分支。显式ABORT、600毫秒心跳超时、CAN/运动异常仍按原机制停止。初始锁存不是整段防碰撞证明，限定固定模型受控演示。

ABORT用06/action03，同SEQ的81/21 01 00只表示接受；须等81/20 06 00停止完成。82 TERMINATED不是替代。确认失败/超时不能宣称停稳，不自动恢复或HOME；现场硬件急停保持独立。
