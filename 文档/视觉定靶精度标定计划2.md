# 固定工作距离下的视觉定靶精度标定计划

## 1. 目标

本计划用于建立 Jetson 视觉误差 `(dcx, dcy)` 到机械臂末端平面修正量 `(Delta X, Delta Z)` 的可验证关系，并据此设置定靶状态机的对准阈值、步长和发射条件。

目标工作条件如下：

- 目标表面与相机/末端的工作距离固定。
- 定靶时机械臂使用固定的预定位姿态，末端朝向不随对准过程改变。
- 激光只能由 `robot_target` 状态机进入 `TARGET_OUTPUT` 后输出，P000 KEY 仍是最终人工许可。

本计划不以“像素误差小”作为验收标准，而以“目标平面上的实际毫米误差小且可重复”作为验收标准。

## 2. 完成标准

在开始实验前填写以下指标：

| 项目 | 符号 | 目标值 | 实测值 |
|---|---:|---:|---:|
| 激光点有效直径 | `D_laser` | `____ mm` | `____ mm` |
| 允许的最大落点误差 | `E_required` | `____ mm` | `____ mm` |
| 视觉静止 3sigma 误差 | `E_vision_3sigma` | `<= E_required / 2` | `____ mm` |
| 机械臂重复定位 3sigma 误差 | `E_robot_3sigma` | `<= E_required / 2` | `____ mm` |
| 综合 3sigma 误差 | `E_total_3sigma` | `<= E_required` | `____ mm` |

综合误差先按下式估计：

```text
E_total_3sigma = sqrt(E_vision_3sigma^2 + E_robot_3sigma^2)
```

若 `E_total_3sigma > E_required`，不得通过缩小 `TARGET_ALIGN_TOL_PX` 强行进入发射状态；应先处理视觉噪声、相机畸变、传动回差或工作距离重复性。

## 3. 安全前置条件

1. 使用当前已验证可达的预定位姿态，不使用接近关节限位或已出现复位失败的测试点。
2. 每次开始前发送 `target_disable` 和 `laser_off`；标定全过程禁止进入 `TARGET_OUTPUT`。
3. 标定时不按 P000 KEY，激光保持关闭；使用纸面靶、棋盘格或可重复的十字靶替代实际人体目标。
4. 每次机械臂移动后，必须等待 `robot pid run finished!!`，再采集图像数据。
5. 若日志出现 `reject AUTO`、`inverse failed`、关节限位、`soft reset final FAIL` 或 CAN 异常，立即停止本次实验，执行 `target_disable` 和 `soft_reset`。

## 4. 记录约定

所有数据写入 `DEBUG/vision_calibration/`，建议建立以下文件：

```text
camera_intrinsics.yaml          # 相机内参与畸变系数
static_noise.csv                # 静止视觉误差序列
robot_repeatability.csv         # 机械臂重复定位数据
planar_mapping.csv              # X/Z 已知位移与像素变化
calibration_result.md           # 本计划最后的计算结果与参数
```

每条记录至少包含：时间、末端命令位置、实际关节角度、`dcx`、`dcy`、检测置信度、是否到位、图像帧号。

## 5. 阶段 A：确认坐标和参考点

### A.1 固定工作点

1. 用 `soft_reset` 建立可信 HOME。
2. 移动到当前状态机实际使用的 `TARGET_PRE_X/Y/Z` 预定位点。
3. 将纸面十字靶固定在最终工作平面，记录其位置；标定过程中不得移动靶面。
4. 记录此时的末端坐标 `P0 = (X0, Y0, Z0)`、工作距离和相机分辨率。

### A.2 明确视觉误差定义

必须在 Jetson 端确认以下定义，并写入 `calibration_result.md`：

```text
dcx = 目标中心 u - 期望中心 u_ref，或其相反定义？
dcy = 目标中心 v - 期望中心 v_ref，或其相反定义？
u 向右为正；v 向下为正，或实际定义？
```

不能只根据变量名判断方向。后续矩阵的正负号完全由这个定义决定。

### A.3 单次方向验证

在 P0 附近执行不超过 `1 mm` 的安全小位移，分别沿机械臂 `+X` 和 `+Z` 移动一次，观察 `dcx/dcy` 的变化。

验收：先确认“误差增大时机械臂该往哪个方向修正”。若方向相反，先记录符号关系；不要在状态机中反复试错。

## 6. 阶段 B：相机与算法的静止噪声测量

### B.1 相机内参与图像处理

1. 在固定工作距离下，使用棋盘格或 ChArUco 标定相机内参和畸变。
2. Jetson 视觉算法必须在去畸变图像上计算目标中心。
3. 固定曝光、增益、白平衡和焦距；避免自动曝光导致目标边缘与中心漂移。
4. 固定目标、机械臂和相机，连续采集至少 100 帧 `dcx/dcy` 与检测置信度。

### B.2 统计计算

对固定靶的有效帧分别计算：

```text
mean_dcx, mean_dcy
sigma_dcx, sigma_dcy
```

暂未建立平面映射前，仅记录像素噪声；建立映射后再换算为毫米误差。采样过程中出现检测丢失、明显误检或置信度低于约定阈值的帧，单独记录，不混入统计。

### B.3 判定

- 若噪声呈随机小范围波动：后续使用 5 帧中位数作为控制输入。
- 若存在周期性跳变：排查自动曝光、检测框切换、USB 相机丢帧或目标中心算法。
- 若相机静止仍有明显大幅漂移：先修视觉算法，不进入机械臂闭环阶段。

## 7. 阶段 C：机械臂重复定位测量

### C.1 测量方法

以 P0 为中心，在安全范围内重复执行：

```text
P0 -> P1 -> P0
```

其中 P1 是已确认安全的远离 P0 的观察点。重复至少 20 次；每次回到 P0 后等待 `robot pid run finished!!`，记录相机检测到的目标中心。

### C.2 判定

若 P0 的像素中心散布明显大于阶段 B 静止噪声，说明主要问题在机械重复定位、传动回差或控制收敛，而非视觉。此时应优先优化关节 PD、到位确认和机械结构，不应继续缩小视觉阈值。

## 8. 阶段 D：固定平面二维映射标定

### D.1 采集点

以 P0 为基准，使用已验证安全的绝对坐标点，分别采集：

```text
P0
P_X+ = P0 + (Delta X, 0, 0)
P_X- = P0 - (Delta X, 0, 0)
P_Z+ = P0 + (0, 0, Delta Z)
P_Z- = P0 - (0, 0, Delta Z)
```

建议初始 `Delta X = Delta Z = 5 mm`；若像素变化过小或噪声占比过高，可在已确认的安全空间内提高到 `10 mm`。每个点重复采集 5 次，每次取稳定后的 5 帧中位数。

### D.2 计算像素变化矩阵

以图像坐标 `(u, v)` 或与其等价的原始 `dcx/dcy` 记录观测值。计算：

```text
du_dX = (u_X+ - u_X-) / (2 * Delta X)
dv_dX = (v_X+ - v_X-) / (2 * Delta X)
du_dZ = (u_Z+ - u_Z-) / (2 * Delta Z)
dv_dZ = (v_Z+ - v_Z-) / (2 * Delta Z)

B = [ du_dX  du_dZ ]   # 单位 px/mm
    [ dv_dX  dv_dZ ]
```

检查 `det(B)`：若其接近 0，说明画面信息无法区分 X/Z 位移，或标定/坐标方向记录有误；不得继续求逆。

### D.3 得到状态机修正矩阵

若视觉误差定义为：

```text
e_px = [ 目标像素 - 期望像素 ]
```

则消除误差的末端修正为：

```text
Delta_p_arm = -inverse(B) * e_px
```

记：

```text
J = -inverse(B) = [ Jxx  Jxz ]   # 单位 mm/px
                   [ Jzx  Jzz ]

Delta X = Jxx * dcx + Jxz * dcy
Delta Z = Jzx * dcx + Jzz * dcy
```

若 A.3 的单次方向验证显示误差定义相反，则整体正负号相反；必须通过 1 mm 小位移验证后再写入固件。

### D.4 映射验收

选择未参与计算的 4 个验证点，例如 `(±3 mm, ±3 mm)`，用 J 预测修正量并执行一次小步移动。测量剩余误差。

验收标准：映射后的预测残差应小于最终允许误差的 50%。若不满足，检查镜头畸变、相机/激光安装刚性、目标平面是否移动、末端姿态是否改变，以及 X/Z 是否存在明显非线性耦合。

## 9. 阶段 E：两阶段闭环参数设计

完成阶段 D 后，将状态机设为“移动后观察”，避免在机械臂尚未收敛时追逐旧视觉帧。

### E.1 粗对准

| 参数 | 计算/建议 | 最终值 |
|---|---|---:|
| 进入精对准阈值 | `3 * E_required`，且不小于 `E_total_3sigma` | `____ mm` |
| 最大修正步长 | `2~3 mm`，不得超过已验证安全步长 | `____ mm` |
| 每步后等待 | 等待 `robot pid run finished!!`，再额外稳定 `200~300 ms` | `____ ms` |
| 视觉取样 | 连续 5 帧取中位数 | `5 帧` |

### E.2 精对准

| 参数 | 计算/建议 | 最终值 |
|---|---|---:|
| 最大修正步长 | `max(E_required, E_total_3sigma)`，初始不超过 `1 mm` | `____ mm` |
| 发射误差阈值 | `max(E_required, E_total_3sigma)` | `____ mm` |
| 稳定次数 | 连续 `3~5` 次有效观测 | `____ 次` |
| 视觉数据有效期 | 大于一次采样和一次运动等待的总时长 | `____ ms` |

精对准阶段不得按固定 `TARGET_ALIGN_PERIOD_MS` 在前一个 AUTO 尚未结束时再次发送 AUTO。必须等待上一小步完成，重新取样后才允许下一次修正。

### E.3 发射许可条件

只有同时满足以下条件，状态机才可进入 `TARGET_OUTPUT`：

```text
1. robot pid 已完成，末端不再运动；
2. 最近 5 帧视觉中位数对应的毫米误差 <= 发射阈值；
3. 最近 5 帧的误差标准差 <= 稳定阈值；
4. 连续 3~5 次确认均满足；
5. 视觉帧未超时；
6. 所有关节限位、姿态有效和通信状态正常；
7. P000 KEY 被持续按住。
```

任一条件失效，立即保持/切回 `TARGET_ALIGN`，并关闭 P015。

## 10. 阶段 F：固件接入顺序

完成所有测量后，再按以下最小顺序改动固件：

1. 在 Jetson 端固定输出去畸变后的目标中心和检测置信度。
2. 在 RA6M5 端保留现有视觉协议，不修改 `FF 05 03 ... FE` 的帧格式。
3. 将 `TARGET_KX_MM_PER_PX`、`TARGET_KY_MM_PER_PX` 的独立比例修正替换为阶段 D 得到的二维矩阵 J。
4. 新增 5 帧中位数滤波，仅对有效且未超时的视觉帧计算。
5. 将 `TARGET_ALIGN` 改为“发一个 AUTO 小步 -> 等到位 -> 重新采样”的串行节奏。
6. 将确认条件从固定像素阈值改为毫米误差阈值和帧稳定性阈值。
7. 保留 P000、视觉超时、关节限位、`target_disable` 对 P015 的现有安全关闭逻辑。

每完成一项，先用纸面靶完成验证，再进入下一项；禁止同时修改矩阵、阈值、PD 参数和状态机节奏。

## 11. 阶段 G：最终验收测试

### G.1 静态精度

固定靶不动，连续运行 30 次完整定靶流程。记录每次最终毫米误差、是否进入发射许可、是否出现视觉超时。

验收：30 次中不允许有一次在误差超限时进入 `TARGET_OUTPUT`。

### G.2 工作区精度

在固定工作平面内选择至少 9 个点，覆盖目标区域的中心、四角和中间点。每点重复 5 次。

验收：每点的平均误差和 3sigma 误差都不超过 `E_required`；若边缘点明显变差，需要缩小工作区或建立分区标定矩阵。

### G.3 异常安全

分别验证：视觉数据停止、检测置信度不足、P000 松开、限位触发、`target_disable`、CAN 通信异常。

验收：任何异常下 P015 必须保持或立即变为低电平，且状态机不得以旧视觉结果继续发射。

## 12. 结果决策表

| 现象 | 主要原因 | 下一步 |
|---|---|---|
| 静止画面误差大 | 检测/曝光/镜头畸变 | 优先修 Jetson 图像链路 |
| 静止画面稳定，但重复回 P0 误差大 | 关节控制、传动回差或到位判断 | 优先优化机械臂 PD 和到位确认 |
| 中心点准确、边缘点不准确 | 平面映射非线性或镜头残余畸变 | 缩小工作区或分区标定 |
| 修正方向反复错误 | `dcx/dcy` 符号或矩阵符号错误 | 回到 A.3 单次方向验证 |
| 误差在阈值附近来回跳 | 单帧噪声和固定步长过大 | 使用中位数、两阶段步长和稳定性确认 |
| 理论误差已很小但激光仍偏 | 相机-激光外参偏移或安装松动 | 在目标平面重新标定相机到激光的参考中心 |

## 13. 必须确认的信息

在写入最终参数或改动状态机前，需要确认以下信息：

1. 相机是固定在外部，还是刚性安装在机械臂末端？
2. Jetson 当前输出的 `dcx/dcy` 是“目标中心减图像中心”，还是“图像中心减目标中心”？
3. 相机分辨率、镜头焦距/视场角、目标检测方法和是否已有去畸变？
4. 激光点直径和比赛允许的最大落点误差分别是多少毫米？
5. 当前预定位点到目标平面的实际距离、允许的 X/Z 工作范围，以及是否始终保持相同末端朝向？
6. 是否能从 Jetson 同时获得目标检测置信度和原始像素中心 `(u, v)`？

这些答案决定矩阵标定方式、最终毫米阈值和是否需要在 Jetson 端补充滤波；在未确认前，不应写死新的 `TARGET_*` 参数。
