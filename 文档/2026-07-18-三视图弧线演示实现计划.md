# 三视图弧线演示 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增一个不影响比赛三视图状态机的独立演示动作，由上位机一键控制机械臂平滑经过左、正、右三个既有标定视图。

**Architecture:** 上位机只负责顺序发送 `soft_reset`、`auto 0 -130 -15` 和 `view_arc <duration_ms>`，并根据 ARM 日志确认每一步完成。RA6M5 在本地 10 ms 控制周期内生成同步关节轨迹：先平滑进入左视图，再用经过左、正、右三个关节姿态的二次 Bezier 曲线完成连续绕行动作。

**Tech Stack:** RA6M5/FSP、FreeRTOS、C、PySide6、Python 静态与 GUI 测试、Keil MDK

### Task 2: 实现 RA6M5 连续关节轨迹

**Files:**
- Modify: `APP/robot.h`
- Modify: `APP/robot.c`
- Modify: `Middle/robot_cmd.c`

- [ ] **Step 1: 新增最小事件和公开接口**

新增 `ROBOT_VIEW_ARC_EVENT` 和：

```c
int robot_send_view_arc_event(float duration_ms);
```

时长只接受 4000～8000 ms，拒绝安全中止锁存、位姿无效或已有运动忙的请求。

- [ ] **Step 2: 生成平滑进入轨迹**

读取当前 J1～J5 反馈，以五次 smoothstep 在 2000 ms 内同步移动到左视图：J0=65、J3=330、J4=85；其余关节保持当前值。

- [ ] **Step 3: 生成左到右连续轨迹**

使用五次时间缩放后的二次 Bezier 关节曲线：

```text
左：J0=65,  J3=330, J4=85
正：J0=90,  J3=360, J4=80
右：J0=115, J3=395, J4=80
```

控制点按 `C = 2 * Front - (Left + Right) / 2` 计算，使曲线经过正视图。J3 使用 330→360→395 的连续角，交给现有最短角差控制跨越 0°。

- [ ] **Step 4: 复用现有 PID 执行和安全中止**

轨迹写入 `s_result_buf` 并调用现有 `robot_pid_run()`；全过程使用 `ROBOT_STATUS_AUTO_BUSY`，限位/`motion_abort` 可中止。结束后清除 `ROBOT_STATUS_POSE_VALID` 并设置 `ROBOT_STATUS_POSE_DEGRADED`，禁止直接继续 Cartesian AUTO。

- [ ] **Step 5: 增加文本命令**

```text
view_arc 8000
motion_abort
```

`motion_abort` 直接调用现有 `robot_motion_abort()`，停止后必须通过 `soft_reset` 恢复。

**Files:**
- Modify: `UpperComputer/ra6m5_upper_console.py`

- [ ] **Step 2: 增加 ARM 完整行缓存和事件**

串口分片先进入文本缓存，再按完整换行解析。识别 soft reset PASS/FAIL、AUTO 完成、VIEW_ARC 完成/失败和运动中止，供后台编排线程等待。

- [ ] **Step 3: 实现一键流程**

依次执行并等待：

```text
soft_reset -> auto 0 -130 -15 -> view_arc 8000
```

任何阶段失败或超时均发送 `motion_abort`，保留日志并给出中文原因；成功后提示机械臂保持右视图，下一次 AUTO 前需 `soft_reset`。

- [ ] **Step 4: 实现停止操作**

“停止弧线”设置线程停止标志并发送 `motion_abort`、`laser_off`，不自动回 HOME。
