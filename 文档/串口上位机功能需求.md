# 串口上位机功能需求清单

## 1. 设计目标

本上位机用于机械臂调试、演示和比赛现场验证，第一版定位为 Windows 本地工具。软件采用一体化双串口设计，在同一个界面内同时提供机械臂文本控制台和 Jetson 模拟器，不拆成两个独立软件。

核心目标：

- 快速连接机械臂控制串口，发送复位、AUTO、单关节、激光和夹爪调试命令。
- 通过 PC 模拟 Jetson，发送视觉误差帧和定靶状态机启停帧。
- 实时解析 RA6M5 回传状态，明确显示 READY、ALIGN_DONE、OUTPUT_ON/OFF 和 ERROR。
- 自动记录收发日志，便于复现实验和定位问题。
- 在界面层提供安全停止入口，避免调试时激光或视觉连续发送失控。

第一版不做网络控制、数据库、账号权限、插件系统、云端记录和固件参数在线写入。

## 2. 总体架构

上位机包含两条独立串口通道：

| 通道 | 用途 | 默认波特率 | 数据类型 |
| --- | --- | ---: | --- |
| 机械臂控制口 | 发送文本命令，接收机械臂日志 | `115200` | ASCII 文本，命令以 `\r\n` 结尾 |
| Jetson 模拟口 | 模拟视觉端发送二进制帧，接收 RA6M5 状态回传 | `115200` | HEX 二进制帧 |

界面建议采用以下页面或分区：

- 串口连接区
- 机械臂控制区
- AUTO/单关节调试区
- Jetson 模拟器区
- 激光定靶状态机区
- 状态回传区
- 日志区

## 3. 串口连接管理

P0 必做：

- 扫描当前可用 COM 口。
- 分别选择机械臂控制口和 Jetson 模拟口。
- 支持打开、关闭、重连两个串口。
- 显示每个串口的连接状态、端口名、波特率和收发计数。
- 串口打开失败时显示明确错误，不影响另一路串口继续使用。
- 串口断开后停止对应通道的周期发送任务。

P1 建议：

- 保存上次使用的端口和波特率。
- 支持一键重新连接上次配置。

## 4. 机械臂控制模块

机械臂控制口发送文本命令。第一版必须支持以下命令按钮和输入框：

| 功能 | 命令格式 | 说明 |
| --- | --- | --- |
| 软复位 | `soft_reset` | 回 HOME，建立可信 pose |
| 硬复位 | `hard_reset` | 调用固件硬复位逻辑 |
| 读取所有关节 | `read_all` | 读取 J1~J5 实际角度 |
| 笛卡尔 AUTO | `auto <x> <y> <z>` | 发送绝对末端偏移目标 |
| 单关节绝对转动 | `abs_rotate <joint_id> <angle>` | 指定关节转到目标角 |
| 单关节相对转动 | `rel_rotate <joint_id> <delta>` | 指定关节相对转动 |
| 末端画圆 | `circle <time_ms> <radius_mm>` | 调用 time_func 圆轨迹 |
| 启动定靶 | `target_enable` | 启动激光定靶状态机 |
| 关闭定靶 | `target_disable` | 关闭定靶状态机并关激光 |
| 激光调试开 | `laser_on` | 仅用于硬件调试 |
| 激光调试关 | `laser_off` | 仅用于硬件调试 |
| 夹爪打开 | `gripper_open` | 调试夹爪 |
| 夹爪停止 | `gripper_stop` | 停止夹爪 |

命令发送要求：

- 所有文本命令统一追加 `\r\n`。
- AUTO 输入支持浮点数。
- 单关节命令的 `joint_id` 按固件当前定义传入，不在上位机内重新映射。
- 发送前在日志中记录 `[ARM-TX]`，收到日志记录 `[ARM-RX]`。

## 5. AUTO / 单关节 / 复位调试模块

P0 必做：

- `soft_reset` 按钮单独突出显示。
- `auto x y z` 提供三个数值输入框和发送按钮。
- `abs_rotate` / `rel_rotate` 提供关节编号、角度输入和发送按钮。
- `read_all` 结果在日志中保留，并可在状态区显示最近一次 J1~J5 角度。
- 识别关键日志：
  - `soft reset final verify PASS`
  - `soft reset final FAIL`
  - `AUTO final confirm failed`
  - `reject AUTO: pose invalid`
  - `robot pid run finished!!`

P1 建议：

- 支持 AUTO 动作序列编辑和一键执行。
- 每组动作之间支持手动 Enter/确认后继续。
- 支持隐藏轨迹点刷屏日志，只保留关键状态和平均误差。

## 6. Jetson 模拟器模块

Jetson 模拟器用于 PC 端模拟真实 Jetson，调试视觉误差通信和激光定靶状态机。该模块是 P0 必做功能。

### 6.1 启停控制帧

支持手动发送：

```text
AA 01 01 BB   // 请求启动 target 状态机
AA 01 00 BB   // 请求关闭 target 状态机
```

界面至少提供两个按钮：

- 启动状态机
- 关闭状态机

### 6.2 视觉误差帧

支持输入 `dcx` 和 `dcy`，生成并发送视觉误差帧：

```text
FF 05 03 dcx_lo dcx_hi dcy_lo dcy_hi checksum FE
```

计算规则：

```text
checksum = (0x05 + 0x03 + dcx_lo + dcx_hi + dcy_lo + dcy_hi) & 0xFF
```

要求：

- `dcx/dcy` 使用 `int16_t`，小端发送。
- 支持单次发送。
- 支持周期发送，默认周期建议 `200 ms`。
- 周期发送时必须能随时停止。
- 日志中同时记录原始 HEX 和解析后的 `dcx/dcy`。

### 6.3 视觉误差序列

P1 建议支持视觉误差序列编辑，例如：

```text
15,-10:2;8,-5:1;0,0:0
```

含义：

- `15,-10:2`：发送 `dcx=15,dcy=-10` 并保持 2 个周期或 2 次。
- `8,-5:1`：发送 `dcx=8,dcy=-5` 并保持 1 个周期或 1 次。
- `0,0:0`：持续发送零误差，直到收到状态回传或用户停止。

第一版可以只实现“按序发送”，不需要复杂脚本语言。

## 7. 激光定靶状态机模块

状态机调试流程建议做成一个向导式面板：

1. 点击 `soft_reset`，等待 `soft reset final verify PASS`。
2. 点击启动状态机，机械臂控制口发送 `target_enable`，或 Jetson 模拟口发送 `AA 01 01 BB`。
3. 等待 `CC 04 01 DD` 和 `CC 01 01 DD`。
4. 开始周期发送视觉误差帧。
5. 等待 `CC 02 01 DD`，提示“已对准，请按住 P000 KEY”。
6. 等待 `CC 03 01 DD`，显示“激光输出已开启”。
7. 提示“松开 P000 KEY”。
8. 等待 `CC 03 00 DD`，显示“激光输出已关闭”。
9. 停止视觉发送，发送 `target_disable` 或 `AA 01 00 BB`。

安全要求：

- `laser_on/off` 只作为 P801 硬件调试按钮，不属于正式定靶安全链路。
- 正式激光输出必须走 `target_enable + 视觉对准 + P000 KEY`。
- 状态机运行时界面应提示：P000 必须按住才允许输出，松开后应关闭输出。

## 8. 状态回传解析

Jetson 模拟口需要解析 RA6M5 回传：

```text
[0xCC][FUNC][VALUE][0xDD]
```

当前必须识别：

| HEX | 含义 | 状态显示 |
| --- | --- | --- |
| `CC 04 01 DD` | 状态机已启用 | TARGET_CTRL_ON |
| `CC 04 00 DD` | 状态机已关闭或启用失败 | TARGET_CTRL_OFF |
| `CC 01 01 DD` | 预定位完成 | READY |
| `CC 02 01 DD` | 连续稳定对准完成 | ALIGN_DONE |
| `CC 03 01 DD` | 激光输出开启 | OUTPUT_ON |
| `CC 03 00 DD` | 激光输出关闭 | OUTPUT_OFF |
| `CC FE 01 DD` | 限位/急停类错误 | ERROR |

状态灯建议：

- 串口连接
- pose valid
- target enabled
- READY
- ALIGN_DONE
- OUTPUT_ON/OFF
- ERROR

`pose valid` 当前没有独立二进制回传，第一版可通过 `soft reset final verify PASS` 和 `reject AUTO: pose invalid` 日志推断。

## 9. 日志系统

P0 必做：

- 日志自动落盘到用户指定目录，默认可放在上位机运行目录下的 `logs` 文件夹。
- 日志文件名包含时间戳。
- 每条日志包含时间、来源、端口和内容。
- 文本控制口日志使用 `[ARM-TX]` / `[ARM-RX]`。
- Jetson 模拟口日志使用 `[JETSON-TX]` / `[JETSON-RX]`。
- 二进制帧同时保存 HEX 原文和解析结果。

P1 建议：

- 支持关键日志过滤，隐藏大量轨迹点。
- 支持一键导出当前会话日志。
- 支持标记一次实验开始和结束。

## 10. 安全保护

P0 必做：

- 提供醒目的“安全停止”按钮。
- 点击安全停止后按顺序执行：
  1. 停止 Jetson 视觉周期发送。
  2. 发送 `target_disable`。
  3. 发送 `laser_off`。
  4. 在日志中记录安全停止动作。
- 提供“回 HOME”快捷按钮，发送 `soft_reset`。
- 串口断开时自动停止对应串口的周期发送。
- 状态显示中明确区分：
  - `laser_on/off`：硬件调试。
  - `target_enable/disable`：正式状态机控制。
  - P000：正式输出许可。

不做：

- 第一版不承诺机械臂急停功能。
- `target_disable` 只关闭状态机和激光，不取消已经进入固件队列的 AUTO。
- 上位机不绕过 P000 发射许可。

## 11. 优先级清单

### P0 必做

- 双串口连接管理。
- 机械臂文本命令发送。
- Jetson 启停控制帧发送。
- 视觉误差帧生成、单发和周期发送。
- RA6M5 状态回传解析。
- 关键状态灯。
- 日志落盘。
- 安全停止。

### P1 建议

- AUTO 动作序列。
- 视觉误差序列。
- 演示模式。
- 日志过滤。
- 最近一次关节角度显示。

### P2 后续

- `dcx/dcy` 收敛曲线。
- 关节角度趋势图。
- Kp、视觉阈值、步长等参数只读展示。
- 实验报告导出。

## 12. 验收场景

第一版上位机完成后，至少按以下场景验收：

1. 打开机械臂控制串口，发送 `soft_reset`，日志能识别 `soft reset final verify PASS`。
2. 发送 `read_all`，日志能显示 J1~J5 当前角度。
3. 发送 `auto 0 -50 0`，日志能识别 `robot pid run finished!!` 或异常信息。
4. 打开 Jetson 模拟串口，发送 `AA 01 01 BB`，能解析 `CC 04 01 DD`。
5. 状态机预定位完成后，能解析 `CC 01 01 DD`。
6. 周期发送 `dcx=0,dcy=0` 的视觉误差帧，能解析 `CC 02 01 DD`。
7. 按住 P000 后，能解析 `CC 03 01 DD`。
8. 松开 P000 后，能解析 `CC 03 00 DD`。
9. 点击安全停止后，视觉周期发送停止，并发送 `target_disable` 和 `laser_off`。
10. 全流程日志中能看到文本命令、HEX 帧、解析状态和时间戳。

## 13. 默认假设

- 上位机先面向 Windows PC。
- GUI 技术栈后续再定，不在本需求文档中绑定。
- Jetson 模拟功能只用于 PC 调试；真实 Jetson 上线后，上位机仍可作为机械臂控制台和状态观察工具。
- 第一版不修改固件协议，只按当前固件实现适配。
