# 机械臂演示视频拍摄计划

> 目标：用视频证明当前机械臂控制链路的“平滑、可控、安全”。重点展示 100 Hz 控制、S 曲线轨迹、前馈 + P 跟踪、视觉小步精瞄、P015 激光安全联锁，而不是只拍机械臂在动。

## 一、视频主线

建议成片时长控制在 2 分 30 秒到 3 分 30 秒。视频主线按下面顺序组织：

1. 上电与安全默认态：机械臂静止，激光默认关闭。
2. `soft_reset`：机械臂回到 HOME，展示复位后姿态稳定。
3. 基本 AUTO 运动：短距离、长距离、Z 轴运动，展示 S 曲线起停平滑。
4. 多关节协调运动：末端沿斜线或空间路径移动，展示 IK 连续选解和 J6 保持。
5. 视觉定靶精瞄：Jetson 给出像素误差，机械臂按小步逐渐对准目标。
6. 激光输出与安全关断：只在许可和视觉有效时输出，异常或许可撤销时立即关闭。

## 二、拍摄前准备

### 1. 场地与安全

- 桌面清空，机械臂运动范围内不要放无关物品。
- 在桌面贴一张网格纸或标尺，用来观察末端路径是否平滑、是否抖动。
- 目标点用纸靶、十字标记或圆点标记，不要使用反光材料。
- 激光演示时不要直射人体、镜头、镜面或金属反光面。建议让激光打在白色纸靶上，镜头从侧面拍。
- 拍摄时安排一人操作串口或上位机，一人看机械臂和急停。

### 2. 机位

建议至少准备 3 个机位，手机也可以：

| 机位 | 位置 | 用途 |
|---|---|---|
| A 机位 | 机械臂正前方 45 度，广角固定 | 主画面，展示整体姿态和运动流畅性 |
| B 机位 | 侧面，与大臂/小臂运动平面平行 | 展示起步、减速、停止是否平滑 |
| C 机位 | 靠近末端和靶纸 | 展示视觉精瞄、激光打点、末端微小修正 |

拍摄建议：

- 固定机位，尽量不要手持追拍。手持画面会掩盖机械臂本身是否平滑。
- 使用 60 fps 拍摄，后期可以 0.5 倍慢放关键片段。
- 末端可以贴一个颜色明显的小圆点或小贴纸，便于观众观察轨迹。
- 串口日志可以录屏，不建议全程占主画面；关键时刻作为画中画或字幕说明即可。

## 三、推荐演示动作

### 动作 1：上电默认安全态

目的：证明系统默认安全，不是上电就输出激光。

拍摄内容：

- 机械臂上电后保持静止。
- P015 激光保持关闭。
- 串口出现初始化成功信息。

建议字幕：

```text
上电默认安全态：P015 低电平，激光关闭；视觉定靶状态机默认禁用。
```

画面重点：

- 拍到机械臂整体。
- 拍到纸靶上没有激光点。
- 如果有串口录屏，保留 `BSP_UART_Init Success`、`BSP_CAN_Init Success`、控制任务启动日志。

### 动作 2：soft_reset 回 HOME

目的：证明复位链路可用，后续 AUTO 运动有有效位姿基础。

串口动作：

```text
soft_reset
```

拍摄内容：

- A 机位拍整体回位。
- B 机位拍关节靠近 HOME 时的减速和停止。
- 复位完成后停 2 秒，展示末端没有明显抖动。

建议字幕：

```text
soft_reset：自适应等待 + refine 校正，复位后建立有效 HOME 位姿。
```

画面重点：

- 不要剪掉最后停稳的 1 到 2 秒。
- 如果复位日志里有 HOME 校验通过，可以作为画中画短暂出现。

### 动作 3：短距离 X 方向平滑移动

目的：展示短路径下 S 曲线不会突然冲出去，也不会在终点急停。

串口动作：

```text
auto 15 0 0
```

注意：如果现场机械臂坐标系或安全范围不同，使用已经验证过的安全小距离 X 方向目标，不要强行照抄数值。

拍摄内容：

- C 机位拍末端贴纸相对网格纸移动。
- 后期把这一段做 0.5 倍慢放。

建议字幕：

```text
短路径 S 曲线：10 ms 轨迹节点，起步和停止都平滑过渡。
```

画面重点：

- 末端移动距离不用大，关键是起步没有顿挫，终点没有明显回弹。
- 如果能看到末端贴纸沿网格线平稳移动，效果最好。

### 动作 4：Z 方向升降

目的：展示垂直方向控制和多关节协调。

串口动作：

```text
auto 0 0 100
```

注意：该动作在控制文档中作为验证项出现。现场拍摄前仍要先低风险试跑，确认不会碰到机械限位或工作台。

拍摄内容：

- B 机位从侧面拍，突出大臂和小臂的协调。
- C 机位拍末端相对靶纸或标尺的上下移动。

建议字幕：

```text
Z 轴 AUTO：IK 连续选解 + 前馈/P 跟踪，末端升降保持连续。
```

画面重点：

- 让背景有竖直标尺或纸靶边缘，观众能看出末端不是抖着上升。
- 不要只拍关节特写，最好同时能看到末端。

### 动作 5：长距离或斜向空间移动

目的：展示较长路径下“加速段 + 匀速段 + 减速段”的观感。

建议动作：

```text
auto 0 -70 0
auto 0 -140 0
```

或使用现场已验证的两个安全目标点，形成一段较明显的空间移动。

拍摄内容：

- A 机位拍完整动作。
- B 机位拍关节速度从慢到快、再从快到慢的变化。

建议字幕：

```text
长路径 S 曲线：先平滑加速，中段稳定移动，终点平滑减速。
```

画面重点：

- 这一段最适合展示“丝滑”。不要把镜头切太碎，保留完整起步、运行、停止。
- 如果能在后期加一条淡色轨迹线或关键帧圆点，会更容易看出末端路径连续。

### 动作 6：连续多段 AUTO

目的：展示系统可以连续接受多个目标点，每一段都平滑起停。

建议流程：

1. 先执行一个短 X 方向动作。
2. 再执行一个 Z 方向动作。
3. 再回到接近初始位置。

示例：

```text
auto 15 0 0
auto 15 0 60
auto 0 0 0
```

注意：这不是“多段轨迹无停顿融合”。当前实现每段 AUTO 结束后有终点稳定段并批量 stop，所以视频表述应写成“连续多段平滑执行”，不要写成“连续曲线无停顿插补”。

建议字幕：

```text
连续多段 AUTO：每段路径独立规划，终点稳定后进入下一段。
```

画面重点：

- 这段可以用 1.0 倍正常速度，不一定慢放。
- 保留每段停稳瞬间，展示没有明显过冲。

### 动作 7：视觉误差小步精瞄

目的：展示当前项目最有特点的控制闭环：Jetson 给出像素误差，RA6M5 不直接跳目标，而是按毫米级小步接近。

拍摄前提：

- Jetson 能发送合法 0x03 视觉误差帧。
- `ROBOT_TARGET_ENABLED` 已按当前调试方式启用。
- 纸靶在相机视野内，背景不要太乱。

拍摄内容：

- C 机位拍靶纸和末端。
- 串口或 Jetson 侧录屏显示 `dcx/dcy` 逐渐减小。
- 机械臂每 200 ms 左右做一次小步修正。

建议字幕：

```text
视觉小步精瞄：dcx/dcy 映射为 X/Z 修正，单步限制在 ±1.5 mm。
```

继续字幕：

```text
连续 3 个新视觉帧进入 ±30 px 阈值后，状态机确认对准。
```

画面重点：

- 这一段不要追求大动作。小步、稳定、逐渐靠近才是亮点。
- 可以在后期用圆圈标出靶心，用箭头标出末端每次小步修正方向。
- 如果视觉链路现场不稳定，不要硬拍失败画面。可以改拍“手动 AUTO 小步靠近靶心”，并把视觉精瞄留作架构说明字幕。

### 动作 8：激光输出与安全关断

目的：展示激光不是普通开关，而是受状态机约束的安全输出。

正式链路演示：

- 进入 `TARGET_CONFIRM` 后，只有 `fire_allowed=true` 才进入 `TARGET_OUTPUT`。
- `TARGET_OUTPUT` 中视觉仍需保持有效。
- 撤销许可或视觉超时后，P015 立即拉低，激光关闭。

如果当前现场没有方便的发射许可输入：

- 可以只用 `laser_on` / `laser_off` 拍 P015 硬件开关调试能力。
- 字幕必须注明这是“调试命令”，不是正式定靶安全链路。

调试命令：

```text
laser_on
laser_off
```

建议字幕：

```text
P015 激光底层：高电平开，低电平关。laser_on/off 仅用于调试。
```

正式安全字幕：

```text
正式输出只允许在 TARGET_OUTPUT 中发生；视觉超时、限位、许可撤销都会先关激光。
```

画面重点：

- 镜头拍纸靶上的激光点，不要拍直射光路。
- 最好拍到撤销许可或超时后激光点消失。

## 四、展示“丝滑”的拍法

### 1. 用固定背景证明平滑

机械臂本身是立体运动，单看关节容易看不出控制效果。建议在末端后方放网格纸、标尺或黑白棋盘格。末端贴一个红色或黄色小圆点，观众能直接看到末端轨迹。

### 2. 保留完整起停过程

S 曲线的亮点在起步和停止。如果只剪中间匀速段，观众看不出区别。每个动作至少保留：

- 起步前静止 0.5 秒。
- 完整运动过程。
- 到终点后静止 1 秒。

### 3. 拍慢动作，不拍抖动镜头

用 60 fps 拍摄，后期对短距离 X、Z 升降、视觉精瞄三段做 0.5 倍慢放。机位固定比手持跟拍更重要。

### 4. 加简短技术字幕

字幕不要太长，每次只讲一个点：

- `100 Hz 控制周期，每 10 ms 更新轨迹节点`
- `正弦速度 S 曲线，起步和停止平滑`
- `前馈 + P：前馈跟轨迹，P 项修正误差`
- `CAN 并行反馈，减少串行等待抖动`
- `视觉精瞄单步 ≤ 1.5 mm`
- `连续 3 帧进入 ±30 px 后确认对准`
- `异常先关断：视觉超时/限位/许可撤销立即关闭激光`

### 5. 可以做一段对比，但不要伪造旧算法

如果没有旧算法固件，不建议拍“旧 PID vs 新 S 曲线”的伪对比。可以做“普通速度播放 vs 0.5 倍慢放”的同段对比，真实展示当前控制效果。

## 五、建议成片分镜表

| 时间 | 画面 | 动作 | 说明 |
|---|---|---|---|
| 0:00-0:08 | 机械臂全景 + 项目名 | 静止 | 展示设备完整形态 |
| 0:08-0:20 | 靶纸和激光输出区域 | 上电默认关闭 | 说明 P015 默认低电平，激光关闭 |
| 0:20-0:45 | A/B 机位 | `soft_reset` | 回 HOME，姿态稳定 |
| 0:45-1:05 | C 机位 + 网格纸 | `auto 15 0 0` | 短路径 S 曲线，0.5 倍慢放 |
| 1:05-1:25 | B 机位侧拍 | `auto 0 0 100` | Z 轴升降，多关节协调 |
| 1:25-1:50 | A 机位全景 | 长距离或斜向 AUTO | 展示加速、匀速、减速 |
| 1:50-2:20 | C 机位靶纸特写 | 视觉小步精瞄 | 末端逐步靠近靶心 |
| 2:20-2:45 | 靶纸 + 串口/状态画中画 | 激光输出/关断 | 展示许可、超时或撤销后关断 |
| 2:45-3:10 | 全景 + 技术字幕 | 总结控制链路 | 100 Hz、S 曲线、前馈 + P、CAN 并行、安全联锁 |

## 六、现场执行清单

拍摄前确认：

- `soft_reset` 能完成，HOME 校验无 `final FAIL`。
- `read_all` 能正常读到 J1-J5。
- 至少准备 3 个已经试跑安全的 AUTO 目标点。
- 纸靶固定，激光不会照射人眼、镜头或反光面。
- 如果拍视觉精瞄，Jetson 发送的 0x03 视觉误差帧稳定。
- 如果拍正式激光输出，确认发射许可的启用和撤销方式。

拍摄中避免：

- 不要让机械臂贴近限位边界做大动作。
- 不要为了画面效果提高速度或临时改参数。
- 不要把 `laser_on/off` 调试命令说成正式安全输出链路。
- 不要用手扶机械臂或末端辅助完成动作。
- 不要只拍串口日志，必须拍机械臂本体和末端运动。

## 七、最小可拍版本

如果现场时间很紧，至少拍下面 4 段：

1. `soft_reset` 回 HOME。
2. `auto 15 0 0` 短距离 X 方向平滑移动。
3. `auto 0 0 100` Z 方向升降。
4. 激光纸靶开关或正式状态机输出关断。

这 4 段已经能支撑作品说明中的核心结论：机械臂可以稳定复位、按 S 曲线平滑运动，并且激光输出具备默认关闭和可控关断能力。
