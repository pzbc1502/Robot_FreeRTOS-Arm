# 视觉识别技术说明文档

本文档说明当前机械臂点痣项目的视觉识别方案、Qt 界面流程、基准图差分算法、串口交互协议和现场调参方法。

## 1. 系统目标

视觉系统负责从摄像头画面中找到人脸模型上的黑痣目标，计算目标中心相对画面中心的像素误差，并通过串口发送给 RA6M5。RA6M5 根据该误差控制机械臂对准目标。

当前推荐方案是“无黑痣基准图 + 当前画面差分检测”：

```text
机械臂伸展到识别位置
  -> 采集无黑痣基准图
  -> 贴黑痣
  -> 当前画面与基准图配准
  -> 检测新增暗斑
  -> 计算 dcx / dcy
  -> 串口发送给 RA6M5
```

这个方案比普通黑点检测更适合固定人脸模型，因为眼睛、眉毛、鼻孔、嘴巴、底座边缘等固定黑色区域会出现在基准图里，后续差分时不会被当成新增黑痣。

## 3. Qt 界面推荐运行方式

在 Jetson 上运行：

```bash
cd ~/jixiebi/arm_mole_qt
python3 -u -m app.main --camera 0 --width 320 --height 240 --fps 30 --flip none \
    --detector-mode reference \
    --serial-port /dev/ttyUSB0 --baudrate 115200
```

参数说明：

| 参数 | 说明 |
| --- | --- |
| `--camera 0` | 使用 USB 摄像头 0 |
| `--width 320 --height 240` | 摄像头采集分辨率 |
| `--flip none` | 不翻转画面 |
| `--detector-mode reference` | 强制使用基准图差分检测 |
| `--serial-port /dev/ttyUSB0` | RA6M5 串口 |
| `--baudrate 115200` | 串口波特率 |

如果只想先打开界面，不连接摄像头：

```bash
cd ~/jixiebi/arm_mole_qt
python3 -u -m app.main --demo
```

## 4. Qt 界面操作流程

### 4.1 采集基准图

1. 不贴黑痣。
2. 打开 Qt 界面。
3. 点击 `采集基准图`。
4. 如果已连接 RA6M5，Qt 会先发送：

   ```text
   AA 01 01 BB
   ```

5. Qt 等待 RA6M5 回传 `READY`。
6. 收到 `READY` 后，Qt 自动采集多帧画面并取中值。
7. 基准图保存到：

   ```text
   jetson_nano_vision/reference/clean_face.png
   ```

### 4.2 开始识别

1. 贴上黑痣。
2. 点击 `开始识别`。
3. 如果已连接 RA6M5，Qt 会再次发送 `AA 01 01 BB`，等待机械臂伸展到识别位置。
4. 收到 `READY` 后开始连续识别。
5. 画面中显示识别目标、像素坐标、视觉误差和 FPS。

### 4.3 预定位和点痣操作

识别到目标后：

- `预定位`：发送当前目标的视觉误差帧，不触发激光。
- `点痣操作`：发送视觉误差帧，再发送激光输出请求。

注意：`点痣操作` 前必须确认目标识别稳定，且机械臂安全状态正常。

## 5. 基准图差分检测原理

核心代码位于：

```text
jetson_nano_vision/jetson_vision/vision/reference_mole_detect.py
```

算法步骤：

1. 读取无黑痣基准图 `clean_face.png`。
2. 对基准图提取肤色区域，生成检测掩膜。
3. 当前画面与基准图进行 ECC 小幅配准。
4. 将当前画面变换到基准图坐标系。
5. 在 LAB 颜色空间取 L 通道。
6. 通过中位亮度差补偿整体光照变化。
7. 计算 `dark_diff = reference_l - current_l`。
8. 对新增变暗区域做阈值分割。
9. 对候选区域做面积、圆度、实心度、长宽比、平均变暗程度和置信度过滤。
10. 输出置信度最高的黑痣候选目标。

基准检测默认参数：

| 参数 | 默认值 | 作用 |
| --- | ---: | --- |
| `min_area` | `12` | 最小候选面积，过滤噪声点 |
| `max_area` | `500` | 最大候选面积，过滤大块阴影 |
| `min_darkening` | `18` | 单像素变暗阈值 |
| `min_mean_darkening` | `18.0` | 候选区域平均变暗阈值 |
| `min_circularity` | `0.45` | 最小圆度 |
| `min_solidity` | `0.75` | 最小实心度 |
| `min_confidence` | `0.80` | 最小综合置信度 |
| `max_aspect_ratio` | `2.5` | 最大长宽比 |
| `mask_erode` | `7` | 肤色掩膜腐蚀尺寸 |
| `max_translation_px` | `15.0` | 允许的最大配准平移 |
| `max_rotation_deg` | `4.0` | 允许的最大配准旋转 |
| `min_alignment_score` | `0.70` | 最小 ECC 配准分数 |

## 6. 普通黑点检测原理

普通黑点检测位于：

```text
jetson_nano_vision/jetson_vision/vision/mole_detect.py
```

它不依赖基准图，流程是：

```text
BGR 画面
  -> HSV + YCrCb 肤色掩膜
  -> 灰度图 black-hat
  -> 阈值二值化
  -> 形态学开闭运算
  -> 轮廓提取
  -> 面积 / 圆度 / 实心度 / 长宽比 / 对比度过滤
  -> 输出目标
```

这个模式适合快速测试，但容易把眼睛、眉毛、嘴巴、底座黑边识别为黑痣。固定人脸模型场景建议优先使用 `reference` 模式。

## 7. 坐标和误差定义

识别目标中心为：

```text
target_x, target_y
```

画面尺寸为：

```text
frame_width, frame_height
```

视觉误差定义为：

```text
dcx = target_x - frame_width / 2
dcy = target_y - frame_height / 2
```

含义：

- `dcx > 0`：目标在画面中心右侧。
- `dcx < 0`：目标在画面中心左侧。
- `dcy > 0`：目标在画面中心下方。
- `dcy < 0`：目标在画面中心上方。

Qt 侧如果配置了激光偏置，会在发送前修正：

```text
dcx = dcx - laser_offset_x_px
dcy = dcy - laser_offset_y_px
```

相关代码：

```text
arm_mole_qt/app/arm_controller.py
jetson_nano_vision/jetson_vision/vision_protocol.py
```

## 8. RA6M5 串口协议

### 8.1 Jetson 请求机械臂伸展

开启定靶状态机：

```text
AA 01 01 BB
```

关闭定靶状态机：

```text
AA 01 00 BB
```

### 8.2 RA6M5 回传状态

格式：

```text
[0xCC][FUNC][VALUE][0xDD]
```

常用状态：

| FUNC | VALUE | 含义 |
| ---: | ---: | --- |
| `0x01` | `0x01` | `READY`，机械臂已到识别位置 |
| `0x04` | `0x01` | `TARGET_CTRL_ON`，定靶状态机已开启 |
| `0x04` | `0x00` | `TARGET_CTRL_OFF`，定靶状态机关闭 |
| `0xFE` | `0x01` | `ERROR`，RA6M5 上报错误 |

### 8.3 Jetson 发送视觉误差

格式：

```text
[0xFF][0x05][0x03][dcx_lo][dcx_hi][dcy_lo][dcy_hi][checksum][0xFE]
```

其中：

- `dcx` 和 `dcy` 是 `int16_t` 小端。
- `checksum = sum([LEN, FUNC, dcx_lo, dcx_hi, dcy_lo, dcy_hi]) & 0xFF`。

### 8.4 Jetson 请求激光输出

开启激光输出：

```text
AA 03 01 BB
```

关闭激光输出：

```text
AA 03 00 BB
```

## 10. 现场调参建议

### 10.1 误识别多

优先提高以下阈值：

```bash
--ref-min-darkening 25
--ref-min-mean-darkening 25
--ref-min-confidence 0.85
```

现象和处理：

| 现象 | 处理 |
| --- | --- |
| 阴影被识别为黑痣 | 提高 `--ref-min-mean-darkening` |
| 小噪点很多 | 提高 `min_area`，或提高 `--ref-min-confidence` |
| 眼睛眉毛仍被识别 | 重新采基准图，并确认识别时模型位置没有明显变化 |
| 底座边缘被识别 | 限制 ROI 或调整相机视野，减少底座进入画面 |

### 10.2 漏识别

可以降低以下阈值：

```bash
--ref-min-darkening 15
--ref-min-mean-darkening 15
--ref-min-confidence 0.75
```

同时检查：

- 黑痣是否太浅。
- 光照是否太暗。
- 基准图是否在不同姿态或不同光照下拍摄。
- 当前分辨率、`--flip` 是否和基准图采集时一致。

### 10.3 基准对齐失败

如果界面提示 `基准对齐失败`，通常是：

- 摄像头位置变了。
- 人脸模型位置变了。
- 机械臂伸展位置和采基准图时不一致。
- 光照变化过大。

处理方式：

1. 取下黑痣。
2. 保持机械臂在识别位置。
3. 重新点击 `采集基准图`。
4. 再贴黑痣开始识别。

## 11. 使用注意事项

1. 基准图必须在“无黑痣”状态下采集。
2. 采集基准图时，机械臂应先伸到后续识别使用的同一位置。
3. 采集基准图和识别时必须使用同样的 `--width`、`--height`、`--flip`。
4. 相机、模型、光照变化后应重新采集基准图。
5. `reference` 模式下如果没有有效基准图，程序不会使用普通黑点检测兜底。
6. `auto` 模式会在有基准图时使用基准差分，没有基准图时退回普通黑点检测。
7. 真正点痣前应先用 `预定位` 或 `send-serial 0` 模式确认目标稳定。
8. 软件急停没有定义 Jetson 主动急停帧，必须保留独立硬件急停。
