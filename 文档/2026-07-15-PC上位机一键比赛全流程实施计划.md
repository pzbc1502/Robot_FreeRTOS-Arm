# PC 上位机一键比赛全流程 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有 Qt 上位机中保留“一键定靶演示”，新增使用正式 A5 5A + CRC16 协议的“一键比赛全流程”，并打包为可运行 EXE。

**Architecture:** `ra6m5_protocol.py` 负责正式协议组帧和保留 SEQ 的流式解析；`ra6m5_upper_console.py` 继续独占串口，在后台线程中运行比赛流程，通过线程安全状态队列等待同 SEQ ACK 和业务状态。旧定靶演示继续使用原事件接口，新流程与旧演示通过统一互斥标志隔离。

**Tech Stack:** Python 3.11、PySide6、pyserial、pytest、PyInstaller

```python
JETSON_MSG_WORKFLOW_CTRL = 0x06
EVENT_WORKFLOW = 0x20
EVENT_COMMAND_ACK = 0x21
WORKFLOW_START = 0x01
WORKFLOW_FINISH = 0x02
WORKFLOW_ABORT = 0x03

def build_unified_workflow_control_frame(action: int, seq: int) -> bytes:
    if action not in (WORKFLOW_START, WORKFLOW_FINISH, WORKFLOW_ABORT):
        raise ValueError("workflow action must be START, FINISH, or ABORT")
    return build_unified_frame(JETSON_MSG_WORKFLOW_CTRL, seq, bytes([action]))
```

扩展 `Ra6Status`，兼容旧 4 字节帧并保留正式帧的 `seq/event/value/error/msg_type`；正式 `STATUS` 必须读取三字节 payload，正式 `ERROR` 必须保留帧 SEQ。
