## 3.2 运动轨迹与执行控制升级

本系统的机械臂运动控制不再采用简单的等距直线插补和传统 PID 调速，而是采用“视觉误差小步精瞄 + 笛卡尔 S 曲线轨迹 + 逆运动学连续选解 + 前馈 + P 速度闭环”的组合控制方式。该方案的目标是让末端运动在靠近目标时保持平滑、连续和可控，避免因视觉误差突变、关节解跳变或控制周期不一致造成末端抖动。

在视觉定靶阶段，Jetson 端计算靶点中心相对画面中心的像素偏差 `dcx`、`dcy`，RA6M5 只将其作为末端微调量使用，而不是一次性直接跳到最终位置。当前控制侧将像素偏差映射为机械臂笛卡尔坐标中的 X/Z 小步修正：

```text
Δx = clamp(dcx × TARGET_KX_MM_PER_PX, -TARGET_MAX_STEP_MM, +TARGET_MAX_STEP_MM)
Δz = clamp(dcy × TARGET_KY_MM_PER_PX, -TARGET_MAX_STEP_MM, +TARGET_MAX_STEP_MM)

TARGET_KX_MM_PER_PX = -0.38 mm/px
TARGET_KY_MM_PER_PX =  0.35 mm/px
TARGET_MAX_STEP_MM  =  1.5 mm
```

公式含义：`dcx`、`dcy` 表示视觉目标中心相对图像中心的横向和纵向像素误差；`TARGET_KX_MM_PER_PX`、`TARGET_KY_MM_PER_PX` 是像素误差到机械臂末端 X/Z 方向位移的标定系数，正负号表示相机坐标与机械臂坐标的方向关系；`TARGET_MAX_STEP_MM` 是单次精瞄允许的最大位移，`clamp` 用于限制异常视觉误差造成的大幅跳动。

每次精瞄修正都以当前末端位置 `P_cur` 为基准生成新的小目标：

```text
P_next.x = P_cur.x + Δx
P_next.y = P_cur.y
P_next.z = P_cur.z + Δz
```

公式含义：`P_cur` 表示当前机械臂末端实际位置，`P_next` 表示本次视觉修正生成的下一目标点；当前定靶过程只修正 X 和 Z 两个方向，Y 方向保持不变，从而把视觉偏差转换为水平和垂直方向的小步对准动作。

这种做法没有把误差无限累加到旧目标点上，而是按当前实际末端位置逐步修正，能降低旧目标残留和视觉噪声造成的过冲风险。状态机中两次视觉修正的最小间隔为 200 ms，单次修正量限制在 1.5 mm 以内，因此精瞄过程表现为低速、小步、可观察的闭环靠近。

当产生新的笛卡尔目标点后，机械臂进入 AUTO 运动流程。AUTO 运动使用 10 ms 控制周期生成轨迹节点，并采用正弦速度 S 曲线进行路径规划。设当前点到目标点的位移长度为 `S`，路径方向单位向量为 `u`，系统以 `dt = 0.01 s` 对速度曲线积分，得到每个轨迹节点的位移量 `s_i`，再生成笛卡尔路径点：

```text
P_i = P_start + u × s_i
```

公式含义：`P_start` 为本段 AUTO 运动的起点，`u` 为从起点指向目标点的单位方向向量，`s_i` 为第 `i` 个控制周期沿路径方向累计前进的距离，`P_i` 为第 `i` 个笛卡尔轨迹节点。

当前 S 曲线参数为：

```text
SCURVE_VMAX  = 300 mm/s
SCURVE_AMAX  = 500 mm/s²
SCURVE_OMEGA = 2 × SCURVE_AMAX / SCURVE_VMAX
```

参数含义：`SCURVE_VMAX` 表示末端路径允许的最大线速度，`SCURVE_AMAX` 表示允许的最大线加速度，`SCURVE_OMEGA` 由最大速度和最大加速度推导得到，用于确定正弦速度曲线的变化快慢。

对于较长路径，轨迹分为“加速段 + 匀速段 + 减速段”。加速段采用正弦速度剖面，使速度从 0 平滑上升到最大速度；减速段采用对称曲线，使末端速度平滑降到 0。对于较短路径，系统自动降低峰值速度，只生成“加速 + 减速”两段式短路径，避免短距离运动中仍强行达到过高速度。

每一个笛卡尔路径点都会进行逆运动学求解。为了避免机械臂在连续运动中从一个逆解分支突然跳到另一个分支，当前系统加入了 IK 分支锁定策略：根据当前关节角与候选解之间的加权角度距离选择最连续的解，并对非上一帧分支施加切换惩罚。加权系数为：

```text
{20, 15, 12, 5, 3, 1}
```

公式含义：该数组从 J1 到 J6 依次表示各关节在 IK 连续选解中的权重。权重越高，候选解与当前关节角的偏差对评分影响越大，因此前几个关节权重更高，优先保证大臂和小臂姿态连续；J6 不参与整臂轨迹驱动，AUTO 运动中保持进入运动时的 J6 角度。这样可以减少路径中途的姿态突变，提高定靶过程的可重复性。

关节执行层采用前馈 + P 控制器。系统每 10 ms 更新一个轨迹节点，前馈项由相邻两个目标关节角的差值除以 10 ms 得到，表示“按轨迹本来应该走的速度”；P 项根据当前反馈角与目标角的误差进行修正：

```text
error_j = shortest_angle_diff(θ_current_j, θ_target_j)
v_j = feedforward_j + Kp_j × error_j
v_j = clamp(v_j, -200 deg/s, +200 deg/s)
```

公式含义：`θ_current_j` 为第 `j` 个关节的当前反馈角，`θ_target_j` 为轨迹节点给出的目标角，`error_j` 为按最短角度方向计算得到的跟踪误差；`feedforward_j` 为相邻目标角差分得到的轨迹前馈速度，`Kp_j` 为该关节的比例系数，`v_j` 为最终下发前的关节角速度指令。最后一行将速度限制在正负 200 度/秒以内。

各关节使用独立 Kp：

```text
{0.65, 4.00, 2.50, 1.00, 1.00, 10.0}
```

参数含义：该数组从 J1 到 J6 依次表示各关节比例控制系数。不同关节由于减速比、惯量和负载不同，采用独立 Kp 能减少统一参数带来的跟踪误差。当前控制器没有积分项和微分项，因此不会出现传统 PID 的积分饱和问题。前馈项负责跟随规划轨迹，P 项负责消除反馈误差，最终输出在进入电机 RPM 换算前限制在正负 200 度/秒。轨迹结束后，系统还会追加 10 个控制周期的终点稳定段，此时前馈清零，仅保留 P 项收敛，然后再批量停止 J1-J5 电机。

在 CAN 通信方面，系统也进行了同步优化。每个控制周期先并行发送 J1-J5 的角度读取请求，由 CAN 中断按电机地址分发反馈并置位标志，再通过统一等待函数等待全部反馈，当前批量等待上限为 6 ms。速度指令采用非阻塞发送方式，不逐关节等待应答。这样可以减少串行等待造成的控制周期抖动，使 100 Hz 控制节拍更加稳定。

因此，本系统的运动轨迹控制可以概括为：视觉给出像素误差，RA6M5 将误差转换为毫米级小目标；AUTO 模块用 10 ms S 曲线生成平滑笛卡尔路径；IK 模块选择连续关节解；前馈 + P 控制器按 100 Hz 节拍跟踪路径；CAN 并行反馈保证控制输入及时更新。该链路兼顾了比赛演示中的平滑性、稳定性和安全可控性。

## 3.3 联锁、安全保障与数据闭环升级

系统的安全保障不再依赖单一软件许可，而是通过视觉通信校验、状态机约束、本地限位检查、输出默认关闭和状态回传共同实现。整体原则是“默认禁止、显式启用、持续校验、异常先关断”。

视觉通信首先进行严格帧校验。Jetson 只向 RA6M5 发送一种视觉误差帧：

```text
[0xFF][0x05][0x03][dcx_lo][dcx_hi][dcy_lo][dcy_hi][checksum][0xFE]
```

字段含义：`0xFF` 为帧头，`0x05` 为长度字段，`0x03` 为视觉误差功能码，`dcx_lo/dcx_hi` 和 `dcy_lo/dcy_hi` 分别组成小端格式的 `int16_t` 像素误差，`checksum` 为 `LEN + FUNC + DATA...` 的 8 位截断和，`0xFE` 为帧尾。RA6M5 的解析状态机只接受 `SOF=0xFF`、`LEN=0x05`、`FUNC=0x03`、4 字节 payload、正确 checksum 和 `EOF=0xFE` 的完整帧。任何长度错误、功能码错误、checksum 错误或帧尾错误都会被直接丢弃，不会更新视觉误差，也不会触发机械臂动作。这样可以避免串口噪声、半帧数据或旧协议数据被误当成有效目标。

定靶流程由 `robot_target` 状态机统一管理，当前状态链路为：

```text
TARGET_INIT
    -> TARGET_PRE_POSITION
    -> TARGET_WAIT_DETECT
    -> TARGET_ALIGN
    -> TARGET_CONFIRM
    -> TARGET_OUTPUT
    -> TARGET_DONE / TARGET_RECOVER
```

系统上电后，P015 激光控制引脚被初始化为低电平，激光默认关闭。同时，`ROBOT_TARGET_ENABLED` 和 `ROBOT_TARGET_FIRE_ENABLE` 均默认为 `false`。这意味着即使视觉端发送了有效目标，系统在未显式启用定靶流程、未给出发射许可之前，也不会进入正式输出状态。

在 `TARGET_PRE_POSITION` 中，机械臂先移动到预定观察位；到位后 RA6M5 向 Jetson 回传就绪状态。进入 `TARGET_WAIT_DETECT` 后，系统等待 500 ms 内的新视觉误差帧。进入 `TARGET_ALIGN` 后，系统按 200 ms 周期进行小步修正，并要求误差连续 3 个新视觉帧都进入阈值范围：

```text
|dcx| <= 30 px
|dcy| <= 30 px
```

公式含义：`dcx`、`dcy` 分别为视觉目标在横向和纵向上的像素偏差；30 px 是当前代码使用的对准阈值。只有连续 3 帧都满足上述条件后，状态机才进入 `TARGET_CONFIRM`。这避免了单帧识别抖动造成误判。

正式输出只允许在 `TARGET_OUTPUT` 状态中发生。其它状态都会保持或强制执行 `BSP_Laser_Off()`。在 `TARGET_OUTPUT` 中，系统仍然持续检查发射许可和视觉新鲜度：如果 `fire_allowed` 被撤销，或视觉帧超过 500 ms 未更新，系统会立即关闭 P015，并回传输出关闭状态。当前比赛演示阶段，发射许可由 `ROBOT_TARGET_FIRE_ENABLE` 软件变量提供；真实物理发射按键 GPIO 已在 `target_obs_t.fire_button` 中预留，后续可直接替换为硬件输入。

本地安全检查也在每个状态机周期执行。`robot_target_step()` 会检查 `obs->estop_active`、`obs->limit_triggered`，以及所有关节的 `ROBOT_STATUS_LIMIT_HAPPENED` 状态位。若检测到急停、限位或关节限位触发，系统立即关闭激光，向 Jetson 回传错误状态，并进入 `TARGET_RECOVER`。当前代码已经接入关节限位状态检查；独立急停 GPIO 和物理发射按键仍作为接口预留，后续可在硬件分配后接入。
